# Credits — Escape the Midway

All art is drawn procedurally with the Canvas 2D API in `js/art.js` and CSS in `ui.css`.
All sound is synthesised at runtime with WebAudio in `js/audio.js`.
No third-party images, sprites, sounds or libraries are used.

Fonts: IM Fell English / IM Fell English SC by Igino Marini (SIL Open Font License),
loaded by the shared `assets/site.css` from Google Fonts.

If you add a public-domain or CC0 asset, commit it under `tabs/escape/assets/`
and list it here with its source URL and licence. No hotlinking.
